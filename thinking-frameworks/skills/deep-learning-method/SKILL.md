  (3) 특정 자료(논문·책·강의)를 구조적으로 분석하고 내면화할 때 — "이 논문 학습 프롬프트 만들어줘", "이 책 분석해줘", "이 자료 기반으로 공부 도와줘".
  단순 개념 설명 요청("이게 뭐야?")에는 트리거하지 않는다 — 사용자가 '학습 과정 자체'를 원할 때만 트리거한다.

# 심층 학습 프레임워크 (Deep Learning Method)

## 핵심 철학

> "읽어서 아는 것"과 "진짜 아는 것"은 다르다.  
> 전문가는 개념을 암기하는 게 아니라 **세계를 다르게 보는 렌즈**를 장착한다.  
> 이 스킬의 목표는 그 렌즈를 48시간 안에 획득하는 것이다.

---

## 0단계: 학습 세션 설계 (시작 전 반드시)

사용자에게 다음을 먼저 확인한다:

1. **학습 주제**: 무엇을 배우려 하는가?
2. **보유 자료**: 교과서, 논문, 강의 영상 녹취록 등 — 다양할수록 좋다 (단일 소스 지양)
3. **목적**: 개념 이해? 실무 적용? 시험? 연구?
4. **가용 시간**: 48시간 / 1주일 / 장기?
5. **현재 수준**: 완전 초보 / 기본 있음 / 중급

→ 이를 바탕으로 **아래 Phase 중 어떤 것을 몇 개 조합할지** 결정한다.

---

## Phase 1: 뼈대 구축 — 핵심 멘탈 모델 추출

**언제**: 항상, 가장 먼저. 압도감을 제거하고 전체 구조를 먼저 파악.

### 프롬프트 01 — 핵심 멘탈 모델
```
이 분야의 전문가들이 공통적으로 공유하며, 문제를 해결할 때 기반으로 삼는
5가지 핵심 멘탈 모델(Core Mental Models)은 무엇인가?

단순한 개념 정의가 아니라, 전문가들이 세상을 바라보고 판단하는
'근본적인 사고의 틀'을 중심으로 설명해줘.

각 멘탈 모델에 대해:
- 한 줄 정의
- 전문가가 실제로 이것을 쓰는 순간의 예시
- 초보자가 이것 없이 저지르는 전형적인 실수
```

### 프롬프트 01b — 원자 단위 구조화 (Zettelkasten 확장)
```
위 핵심 개념들을 '원자 단위'로 쪼개줘.
각 개념이 다른 개념과 어떤 관계인지 아래 형식으로 표시해줘:
- A → B: "A는 B의 전제조건"
- A ↔ B: "A와 B는 상호 보완"  
- A ⊃ B: "A는 B의 상위 개념"
- A ≠ B: "A와 B는 흔히 혼동되지만 다름"
```

## Phase 2: 지형도 그리기 — 논쟁점과 합의점

**언제**: Phase 1 이후. 비판적 사고를 위해 분야의 '전선'을 파악.

### 프롬프트 02 — 지적 지형도
```
이 분야의 전문가들이 현재 근본적으로 의견이 갈리는 3가지 핵심 지점은 어디인가?

각 논쟁에 대해:
- 진영 A의 가장 강력한 논거
- 진영 B의 가장 강력한 논거
- 현재 증거의 무게가 어느 쪽에 더 실려 있는지

반대로, 모든 전문가가 동의하는 '결론이 난 부분'은 무엇인지도 정리해서
이 분야의 전체적인 '지적 지형도'를 그려줘.
```

### 프롬프트 02b — Pre-mortem 검증
```
내가 이 분야의 지식을 실제로 적용한다고 가정해줘.
6개월 후에 완전히 실패했다면, 가장 가능성 높은 이유 5가지는 뭐야?

그리고 그 실패를 예방하기 위해 내가 지금 더 깊이 이해해야 할 개념을
우선순위 순으로 알려줘.
```

---

## Phase 3: 가짜 이해 파괴 — 깊은 이해 검증

**언제**: 개념을 '읽은 것 같다'는 느낌이 들 때. 이 단계가 핵심이다.

### 프롬프트 03 — 변별력 질문 생성
```
이 주제를 단순히 사실로 암기한 사람과 원리를 깊이 있게 이해한 사람을
완벽하게 구분해낼 수 있는 날카로운 질문 10가지를 생성해줘.

조건:
- 정답 암기가 아닌 논리적 추론이나 개념 간 연결성을 증명해야 하는 질문
- "왜?", "어떻게 알 수 있어?", "이 경우엔 어떻게 되지?" 형태
- 전문가도 잠깐 생각해야 하는 수준
```

> **중요**: 이 질문들에 AI 도움 없이 먼저 스스로 답을 적어본다.  
> 막히는 지점 = 진짜 모르는 곳. 이 과정이 전체 학습의 핵심이다.

### 프롬프트 03b — 소크라테스 모드 (선택)
```
나는 [주제]를 이해하려 하고 있어.
정답을 알려주지 말고, 소크라테스처럼 질문으로만 나를 이끌어줘.

내가 대답할 때마다:
- 내 답변의 논리적 허점을 짚는 질문을 던져줘
- 내 답변이 틀리면 직접 고쳐주지 말고 반례를 제시해줘
- 내가 핵심 원리에 스스로 도달할 때까지 계속해줘
```

---

## Phase 4: Feynman 검증 — 설명 가능성 테스트

**언제**: Phase 3 이후, 또는 특정 개념이 도저히 이해되지 않을 때.

### 프롬프트 04 — Feynman 갭 분석
```
내가 [개념]에 대해 설명해볼게:

[본인의 설명 입력]

위 설명을 들었을 때, 12살 아이가 "그게 무슨 말이야?"라고 물을 것 같은
지점 3가지를 찾아줘.

그리고 각 지점이 내 이해의 어떤 공백을 의미하는지 분석해줘.
마지막으로, 가장 쉬운 비유나 구체적인 예시로 그 공백을 채워줘.
```

---

## Phase 5: 피드백 루프 — 오답 교정

**언제**: Phase 3의 질문에 직접 답한 뒤.

### 프롬프트 05 — 오답 분석
```
위 질문들에 대한 내 답변:

[본인의 답변 입력]

피드백을 줘:
- 내가 논리적으로 비약하거나 오해한 부분
- 전문가 관점에서 내가 놓친 핵심 개념이나 맥락
- 부분적으로 맞지만 더 정확하게 표현해야 할 부분

엄격하게 지적하되, 각 지적에 소스나 근거를 포함해줘.
```

---

## Phase 6: Interleaving 테스트 — 실전 경계 판단 (선택)

**언제**: 비슷한 개념 여러 개를 학습한 뒤. 개념의 경계를 실전 수준으로 확인.

### 프롬프트 06 — 혼합 문제
```
[개념 A]와 [개념 B]를 혼합한 문제를 5개 만들어줘.

조건:
- 두 개념 중 어떤 것을 써야 하는지 명확하지 않게 설계
- 내가 두 개념의 경계를 스스로 판단해야 함
- 실제 전문가가 마주칠 법한 현실적인 시나리오
```

## 학습 모드 선택 가이드

트리거 상황 3가지에 맞는 기본 Phase 조합:

| 상황 | 추천 Phase 조합 | 핵심 포인트 |
|------|----------------|------------|
| **① 새 주제 빠르게 마스터** | 0 → 1 → 2 → 3 → 5 | 48시간 기준. 지형도로 방향 잡고 자가 검증 |
| **② 원리 깊이 이해** | 0 → 1 → 3 → 3b → 4 → 5 | 소크라테스 모드 + Feynman 검증이 핵심 |
| **③ 논문/책 구조적 분석** | 0 → 1b → 2 → 3 → 5 | Zettelkasten 원자화 + 지형도로 맥락화 |
| 유사 개념 경계가 헷갈릴 때 | 1b → 6 → 5 | Interleaving 혼합 문제로 경계 확인 |
| 실무 적용 전 자기 검증 | 2b → 3 → 6 | Pre-mortem + 혼합 문제 |
| 장기 지식 체계 구축 | 전체 + 1b 반복 | Zettelkasten을 매 세션마다 누적 |

## 학습 효율 극대화 3가지 원칙

1. **자료의 다양성**: 교과서 2~3권 + 최신 논문 10편 이상 + 강의 녹취록 혼합. 단일 소스는 논쟁점을 숨긴다.

2. **유창성의 함정 경계**: AI 도움 없이 먼저 답을 적어볼 것. Phase 3의 질문에 직접 답하는 시간이 전체의 1/3 이상이어야 장기 기억으로 전환된다.

3. **막히면 비유 요청**: 
```
이 개념을 내가 이미 아는 [비슷한 개념]과 비교하거나,
아주 쉬운 비유로 다시 설명해줘.
그리고 이 비유가 정확하지 않은 부분도 함께 말해줘.
```

## 응답 형식 지침

이 스킬을 사용할 때 Claude는:

1. **0단계 먼저**: 주제, 자료, 목적, 시간, 수준을 확인한다
2. **Phase 선택 제안**: 상황에 맞는 Phase 조합을 먼저 제안한다
3. **프롬프트 즉시 실행**: 사용자가 원하면 직접 Phase를 실행한다
4. **진행 중 피드백**: 각 Phase 완료 후 다음 단계를 안내한다
5. **한국어 우선**: 별도 지시 없으면 한국어로 응답한다
