# 전문 사주명리 분석 스킬

## 핵심 원칙

이 스킬은 **고전 명리 문헌의 이론적 근거**와 **인과관계 기반 논리**를 결합하여 단순 길흉 판단이 아닌 **메커니즘 중심 분석**을 제공한다. 사주를 "맞추는" 것이 아니라 **왜 그런 현상이 나타나는지를 설명**하는 것이 목표다.

> 분석 깊이는 사용자 요청 수준에 따라 조절한다:
> - 간단한 질문 → 핵심 요점 중심으로 간결하게
> - "자세히", "연구 수준", "전문가 수준" 요청 → 고전 인용 포함 완전 분석
> - 세운·월운 질문 → 원국과의 상호작용 중심으로 분석

---

## 분석 입력 수집

사주 분석 전 반드시 확인할 정보:

```
필수: 생년월일시(양력/음력 구분), 성별, 출생지(지역시 보정용)
선택: 현재 관심사(직업/재물/건강/연애/결혼), 분석 깊이 선호도
```

입력이 불완전할 경우:
- 생시 미상 → 주요 후보 2~3개 제시 후 맥락으로 좁힘
- 양음력 불명 → 양력 기준으로 우선 처리 후 명기
- 출생지 미상 → 한국 기준(+30분 표준시) 적용

## 분석 7단계 프레임워크

### STEP 1: 원국 구조 파악 (가장 먼저)

**1-1. 일간(日干) 확정과 오행 강약**

일간이 분석의 출발점. 천간 10개의 오행·음양·특성을 정확히 파악한다.

| 일간 | 오행 | 특성 요약 | 《적천수》 핵심 구절 |
|------|------|-----------|-------------------|
| 甲木 | +목 | 거목, 독립성, 성장 | "甲木參天，脫胎要火" |
| 乙木 | -목 | 덩굴, 유연성, 적응 | "乙木雖柔，刲羊解牛" |
| 丙火 | +화 | 태양, 열정, 발산 | "丙火猛烈，欺霜侮雪" |
| 丁火 | -화 | 촛불, 정밀, 문명 | "丁火柔中，內性昭融" |
| 戊土 | +토 | 산악, 두터움, 중립 | "戊土固重，旣中且正" |
| 己土 | -토 | 전답, 수용성, 육성 | "己土卑濕，中正蓄藏" |
| 庚金 | +금 | 원석, 강직, 숙살 | "庚金帶殺，剛健為最" |
| 辛金 | -금 | 보석, 예민, 정밀 | "辛金軟弱，溫潤而清" |
| 壬水 | +수 | 대해, 유동성, 지략 | "壬水通河，能洩金氣" |
| 癸水 | -수 | 이슬비, 섬세함, 침투 | "癸水至弱，達於天津" |

**1-2. 신강/신약 판정 (삼득법)**

```
득령(得令): 월지가 일간을 생·비하는가?
득지(得地): 일지·기타 지지에 일간의 뿌리가 있는가?
득세(得勢): 천간·지지 전체에서 아군(비겁+인성) > 적군(식상+재성+관살)?

→ 2가지 이상 충족 시 신강(身强), 1가지 이하 신약(身弱)
→ 신강·신약 경계가 모호하면 중화(中和)로 처리
→ 종격(從格) 가능성: 일간과 동류가 8자 중 7자 이상 → 종격 검토
```

**1-3. 격국(格局) 성립** — 《자평진전》 격국론

```
월지 지장간 중 천간에 투출한 글자 = 격(格)
- 정격(正格) 8종: 정관·편관·정재·편재·정인·편인·식신·상관
- 투출 글자가 없거나 복수일 때: 본기 우선, 월지 본체격 적용
- 잡격(雜格): 건록격·양인격·종격·화격 등
```

**성격(成格)/패격(敗格) 판단:**
- 성격: 격의 기신이 없거나, 있어도 합·충으로 해소됨
- 패격: 기신이 격을 직접 공격하고 구신도 없음
- 구격(救格): 패격이지만 구신이 기신을 제거함

**1-4. 용신(用神) 5종 결정**

```
억부용신(抑扶): 신강 → 설·극(식상·재성·관살), 신약 → 생·비(인성·비겁)
조후용신(調候): 《궁통보감》 기준 — 계절의 한열조습 균형
통관용신(通關): 양 세력 대치 시 중간 오행으로 소통
병약용신(病藥): 사주의 病을 찾고 그것을 제거하는 藥이 용신
전왕용신(專旺): 종격은 가장 강한 오행이 용신
```

| 용신 유형 | 배정 오행 | 십성명 | 의미 |
|-----------|-----------|--------|------|
| 용신(用神) | | | 핵심 도구, 대운에서 강화되면 大吉 |
| 희신(喜神) | | | 용신 보조, 있으면 유리 |
| 기신(忌神) | | | 용신 방해, 피해야 할 기운 |
| 구신(仇神) | | | 기신의 응원군 |
| 한신(閑神) | | | 중립, 길흉 불명 |

> **참조**: 상세 고전별 용신론 → `references/classical-theory.md` §용신론

### STEP 2: 십성(十星) 배치와 삶의 구조

십성 = 일간과 다른 7자의 관계. 어느 자리(년·월·일·시)에 있는가가 핵심.

**자리별 의미:**
```
년주(年柱): 조상·초년운(0~15세)·사회·시대적 배경
월주(月柱): 부모·청년운(16~30세)·직업환경·형제
일주(日柱): 자신·배우자·40대
시주(時柱): 자녀·말년운(50세~)·개인 목표
```

**비겁·식상·재성·관성·인성의 과다/과소 판단:**
- 과다(3자 이상): 그 십성의 부정적 측면이 강화됨
- 부재(0자): 그 영역이 취약하며 대운에서 유입 시 강한 반응

**핵심 구조 패턴 (빠른 진단):**

| 패턴 | 원국 특징 | 삶의 경향 |
|------|-----------|-----------|
| 비겁태왕+무재 | 금·목 일색 | 군겁쟁재, 독립 사업 유리, 협업 불리 |
| 식상과다+관성약 | 창의↑ 규율↓ | 자유업 선호, 조직 부적응 |
| 인성과다+식상약 | 의존성, 생각↑ 실행↓ | 학문·연구 적성, 효신탈식 주의 |
| 관살혼잡 | 丙丁 혼재 | 직장 변동 빈번, 관재구설 주의 |
| 재다신약 | 재물은 많으나 일간 약 | 재물 관리 어려움, 건강 소홀 |

### STEP 3: 지지 형충회합(刑沖會合) — 가장 중요

《삼명통회》: "地支为根基，刑冲会合乃命运变化之枢机(지지는 뿌리이며 형충회합은 운명 변화의 핵심이다)"

**합(合) — 변화와 결합:**

```
육합(六合): 子丑·寅亥·卯戌·辰酉·巳申·午未
→ 두 지지가 합하여 새로운 오행으로 변화 또는 기존 성질 약화

삼합(三合): 申子辰水局 / 亥卯未木局 / 寅午戌火局 / 巳酉丑金局
→ 생지·왕지·묘지가 결합. 왕지가 없으면 반합
→ 원국 삼합 + 대운·세운으로 완성 시 "三合局 완성" = 강력한 변화

방합(三會): 亥子丑水 / 寅卯辰木 / 巳午未火 / 申酉戌金
→ 삼합보다 강력. 시간·공간의 완전한 집결
```

**충(沖) — 변화와 분리:**

```
육충(六沖): 子午·丑未·寅申·卯酉·辰戌·巳亥
→ 충은 파괴이자 변화의 에너지. 일지 충은 배우자궁·기반 동요
→ 역마충(寅申·巳亥): 이동·이직·해외 변화
→ 화개충(辰戌·丑未): 내면 갈등, 종교·철학적 변화

충의 해석 원칙:
- 신강 사주 + 기신 충 = 길(기신이 충거)
- 신약 사주 + 용신 충 = 흉(용신이 충거)
- 대운에서 오는 충 > 세운 충 (영향력 10년 vs 1년)
```

**형(刑) — 내부 긴장과 자기 파괴:**

```
삼형(三刑): 寅巳申 / 丑戌未(지세지형) / 子卯(무례지형) / 辰辰·午午·酉酉·亥亥(자형)
→ 충보다 은밀하고 만성적. 법적 문제·건강·인간관계 마찰
```

**형충회합 우선순위:**
```
원국 > 대운 > 세운 > 월운
합 완성 후 충 = 충의 힘이 약화
충 후 합 = 합의 견고도 약화
```

### STEP 4: 대운(大運) 분석

《자평진전》: "운은 사주의 확장. 사주는 씨앗이고 운은 토양·계절이다"

**대운 분석 3층 구조:**

```
Layer 1: 대운 천간이 일간과 어떤 십성 관계인가?
         → 용신 천간 = 길운, 기신 천간 = 흉운

Layer 2: 대운 지지가 원국 지지와 어떤 형충회합을 형성하는가?
         → 가장 중요한 층위

Layer 3: 대운 천간+지지 내부 관계
         → 천간과 지지가 상생·상극 관계인지
```

**대운 10년 전반/후반 구분:**
- 전반 5년: 천간의 영향 우세
- 후반 5년: 지지의 영향 우세
- 전환기(4~6년차): 천간과 지지의 충돌 또는 협력

**대운 길흉 판단표:**

| 대운 글자 | 일간과 관계 | 원국 주요 지지와 관계 | 종합 판단 |
|-----------|-------------|----------------------|-----------|
| 용신 천간 | 직접 강화 | 합·생 | 최길 |
| 희신 지지 | 간접 지원 | 안정 | 길 |
| 기신 천간 | 직접 손상 | 충·극 | 흉 |
| 구신 지지 | 기신 강화 | 형·해 | 대흉 |

### STEP 5: 세운(歲運) 분석

세운은 대운의 환경 위에서 구체적 사건을 촉발하는 방아쇠.

**세운 분석 순서:**

```
1. 세운 천간 → 일간과의 충·합·생극 관계
2. 세운 지지 → 원국 지지 + 대운 지지와의 삼합·방합·충·형 완성 여부
3. "삼합·방합 완성" 여부를 가장 먼저 확인 — 이것이 그 해의 핵심 이벤트
4. 세운의 12운성 → 그 해 사건의 에너지 강도
```

**세운 × 대운 상호작용 (가장 중요한 조합들):**

| 조합 | 현상 |
|------|------|
| 대운 지지 + 세운 지지 = 삼합 완성 | 그 오행의 폭발적 강화, 관련 영역 대변혁 |
| 대운 천간 + 세운 천간 = 천간합 | 해당 십성이 합거(合去), 일시적 무력화 |
| 세운이 원국 일지를 충 | 배우자·기반 이동·이직 |
| 세운 기신 + 원국 기신 겹침 | 흉사 발생 위험 극대화 |
| 세운 용신 + 대운 용신 | 최대 길운, 인생 전환점 |

### STEP 6: 신살(神殺)과 길성(吉星)

신살은 사건의 양상을 구체화한다. 홀로 길흉을 결정하지 않으나, 격국·용신이 작동할 때 그 방향을 구체화한다.

> 상세 신살 목록과 의미 → `references/shinsal-guide.md`

**핵심 신살 빠른 참조:**

| 신살 | 산출 기준 | 핵심 의미 |
|------|-----------|-----------|
| 역마살(驛馬殺) | 寅申巳亥 일지 기준 | 이동·이직·해외 |
| 도화살(桃花殺) | 子午卯酉 | 매력·인기·이성인연 |
| 화개살(華蓋殺) | 辰戌丑未 | 예술·종교·고독 |
| 괴강살(魁罡殺) | 庚辰·庚戌·壬辰·壬戌 일주 | 강렬한 성격, 극단적 운명 |
| 양인살(羊刃殺) | 일간 기준 칼날 지지 | 강한 추진력, 관재·사고 주의 |
| 천의성(天醫星) | 일지 기준 | 의료·치유 적성 |
| 금여성(金輿星) | 일간 기준 | 귀인 인연, 좋은 배우자 |
| 문창귀인(文昌貴人) | 일간 기준 | 학문·지식 능력 |
| 현침살(懸針殺) | 甲申·甲午·辛卯·壬子 등 | 의료·침술·예리한 도구 관련 |

**12운성 에너지 강도표:**

```
제왕(帝旺) > 건록(建祿) > 관대(冠帶) > 장생(長生) > 목욕(沐浴)
> 쇠(衰) > 병(病) > 사(死) > 묘(墓) > 절(絶) > 태(胎) > 양(養)
```

### STEP 7: 조후(調候)와 보조 분석

**조후(調候) — 《궁통보감》 기준:**

사주의 기후적 균형. 극한(極寒)·극열(極熱)·극조(極燥)·극습(極濕) 여부를 판단하여 조화를 맞추는 글자를 찾는다.

```
월지별 핵심 조후:
子·丑·亥 (동절) → 丙火·丁火가 조후용신
午·未·巳 (하절) → 壬水·癸水가 조후용신
寅·卯·辰 (춘절) → 庚金·丙火 균형
申·酉·戌 (추절) → 丙火·壬水 균형
```

> 월지별 일간 조후 상세표 → `references/gungthong-bogam.md`

### 일반 사용자 요청 시 (간결 버전)


## 고전 문헌 인용 원칙

1. **직접 인용**: 원문(한문) + 해석을 함께 제시
2. **문헌 선택 기준**:
   - 격국·용신론 → 《자평진전》 우선
   - 조후론 → 《궁통보감》 우선
   - 일간 특성·신살 → 《적천수천미》·《삼명통회》
   - 일주론 → 《삼명통회》·《명리정종》
   - 대운·세운 사건 예측 → 《연해자평》
3. **인용 남용 금지**: 분석에 직접 연관된 문헌만 인용. 장식용 인용 지양.

> 주요 고전별 핵심 이론 요약 → `references/classical-theory.md`

## 자미두수(紫微斗數) 보조 분석

사주명리와 자미두수를 함께 분석할 때의 통합 원칙:

```
1. 명리사주를 1차 분석 프레임으로 사용
2. 자미두수는 보조 검증 도구로 활용
3. 두 체계가 일치하는 지점 = 고확률 예측
4. 두 체계가 불일치하는 지점 = 복수 가능성 제시

자미두수 보조 분석 포인트:
- 명궁(命宮) 주성(主星)과 사주 일간의 성정 비교
- 재백궁(財帛宮) 화록(化祿)·화권(化權) → 재물 시기 검증
- 질액궁(疾厄宮) 화기(化忌) → 건강 취약 시기 교차 확인
- 부처궁(夫妻宮) 화성 → 연애·결혼 시기 검증
- 유년(流年) 궁선 → 세운 분석과 크로스체킹
```

> 자미두수 기본 이론 및 주성 특성 → `references/ziwei-doushu.md`

## 자주 묻는 질문별 분석 포커스

| 질문 유형 | 핵심 분석 포인트 |
|-----------|-----------------|
| "올해 취업/이직 될까요?" | 관성의 세력 + 세운 관성 투출 + 일지 충여부 |
| "돈은 언제 벌 수 있나요?" | 재성 세운 + 식신생재 패턴 + 비겁 제압 여부 |
| "결혼은 언제 할까요?" | 여: 관성 세운 / 남: 재성 세운 + 배우자궁(일지) 합충 |
| "건강이 걱정돼요" | 조후 균형 + 용신 손상 여부 + 해당 오행 신체 부위 |
| "사업해도 될까요?" | 식신·상관 세력 + 재성 + 비겁태왕 여부 + 대운 방향 |
| "대운이 좋은가요?" | 용신/기신 여부 + 원국 지지와의 형충회합 |

## 윤리적 분석 원칙

1. **확률적 언어 사용**: "~할 가능성이 높다", "~에 유리한 구조다" — 단정적 예언 지양
2. **행위 주체성 강조**: 사주는 경향성이지 운명 결정론이 아님. 사용자의 선택과 노력이 결과를 바꾼다.
3. **민감 주제 처리**: 사망·이혼·중병 등은 "건강에 유의가 필요한 구간", "관계 변화가 예상되는 시기"로 완곡하게 표현
4. **의존성 경계**: 사주 분석은 참고 도구. 중요한 결정은 사용자 스스로 하도록 안내
