# 특수 격국·일주 분석 가이드

## 종격(從格) 판단

### 성립 조건
```
1. 일간이 극히 약하고(월지 실령, 지지 뿌리 없음)
2. 원국의 특정 오행이 6~7자를 장악
3. 일간을 돕는 인성·비겁이 없거나 합거(合去)됨
→ 일간이 강자를 따른다(從)
```

### 종격 유형

| 종격 | 따르는 오행 | 용신 | 기신 |
|------|------------|------|------|
| 종아격(從兒格) | 식상 | 식상·재성 | 인성·비겁 |
| 종재격(從財格) | 재성 | 재성·관성 | 비겁·인성 |
| 종살격(從殺格) | 관살 | 관살·인성 | 비겁·식상 |
| 종왕격(從旺格) | 비겁 | 비겁·인성 | 재성·관살 |
| 종강격(從强格) | 인성+비겁 | 인성·비겁 | 식상·재성 |

### 주의사항
```
종격은 한 글자라도 일간의 뿌리가 있으면 성립하지 않음
종격 사주에서 기신 운이 오면 "종격 파격" — 극심한 흉사
특히 종살격에서 비겁 운 = 대흉
```

## 화격(化格)

### 천간합화 5종

| 합 | 화오행 | 성격 조건 | 예시 |
|----|--------|-----------|------|
| 甲己합 → 土 | 화토격 | 戊己土 월령 또는 지지 토왕 | 甲일간·己월간 |
| 乙庚합 → 金 | 화금격 | 申酉 월령 또는 庚辛 왕 | 乙일간·庚월간 |
| 丙辛합 → 水 | 화수격 | 亥子 월령 또는 壬癸 왕 | 丙일간·辛월간 |
| 丁壬합 → 木 | 화목격 | 寅卯 월령 또는 甲乙 왕 | 丁일간·壬월간 |
| 戊癸합 → 火 | 화화격 | 巳午 월령 또는 丙丁 왕 | 戊일간·癸월간 |

```
화격 성립 시: 화기(化氣) 오행이 용신
화격 파격 시: 파격 오행이 극기신 — 대흉
```

## 특수 일주 (괴강 외)

### 간여지동(干支同體) 6일주

```
甲寅·乙卯·庚申·辛酉·壬子·癸亥
→ 천간과 지지가 동일 오행
특성: 강한 자아 정체성, 극단적 성정, 굽히지 않음
긍정: 자기 확신, 전문성, 지조
부정: 고집, 타협 불능, 고독
```

**경신(庚申) 일주 세부 특성:**
```
건록(建祿) + 비견(比肩)이 일지에 = "자신이 자신의 사용자"
강한 독립성·자존심·원칙주의
배우자 자리(일지)도 자신과 같은 성질 → 부부 자존심 충돌 가능
여명: 배우자가 강직한 성격, 또는 강한 여성 기질
```

### 괴강격(魁罡格) 상세

```
해당 일주: 庚辰·庚戌·壬辰·壬戌 (4개만)
일부 학파: 戊戌 포함 (5개)

성격 특성:
- "魁罡"은 하늘의 가장 강한 강신(剛神)이 집결한 자리
- 극단적 성격: 성공하면 대성취, 실패하면 처참
- 수재·군인·외과의사·형사 직업군에 많음
- 여명 괴강: 전통적으로 "남편 극"으로 봤으나
  현대적 해석: 강한 독립적 여성, 전문직 우수

괴강격 길흉 판단:
- 재성·관성 없이 신왕 = 고독하나 자수성가
- 형충 없는 원국 = 안정적 성취
- 괴강 충: 대파 — 수술·이혼·사고·소송 등 극단 사건
- 대운·세운에서 괴강 충 글자 = 위험 구간
```

## 특수 구조 패턴

### 살인상생(殺刃相生)
```
구조: 칠살(偏官) + 양인(羊刃)이 함께 있을 때
의미: 강한 살기(殺氣)를 양인이 제어 → 최강의 힘
직업: 군인·경찰·외과의사·검사·무술인
주의: 제살이 없으면 양인이 더 흉하게 작용
```

### 살인화(殺刃化)
```
구조: 편관 + 식신 제살 완성
의미: 위험한 힘을 기술로 제어 → 사회적 성취
직업: 고위 공직자, 기업 CEO, 전문 기술직
```

### 군겁쟁재(群劫爭財)
```
구조: 비겁 3자 이상 + 재성 1자
의미: 무리 지은 비겁들이 하나의 재물을 쟁탈
결과: 재물 들어와도 빠져나감, 동업·합자 위험
해법: 관살로 비겁 제압 + 재성 보호
```

### 효신탈식(梟神奪食)
```
구조: 식신 + 편인이 같이 있을 때 (편인이 식신을 극)
의미: 재능 발휘 차단, 시작은 있고 끝이 없음
발동 조건: 대운·세운에서 편인 강화 시
결과: 건강 문제(소화기), 사업 중단, 자녀 문제
해법: 재성으로 편인 제어 (財剋印)
```

### 식신제살(食神制殺)
```
구조: 편관(칠살) + 식신이 같이 있을 때
의미: 가장 위험한 힘을 기술·지혜로 제어
길격의 조건: 식신이 칠살을 완전히 제어할 만큼 강할 것
직업: 전문 기술 + 리더십이 요구되는 분야
```

## 형충회합 심화

### 자형(自刑) — 같은 글자의 충돌
```
辰辰·午午·酉酉·亥亥
의미: 자기 자신과의 싸움 — 자해, 자기 파괴, 내면 갈등
심리: 완벽주의·자책 경향
건강: 만성 스트레스, 자가면역 질환
```

### 삼형(三刑) — 상세
```
寅巳申: 持勢之刑 — 세력을 믿고 방자함. 의지가 강하나 법적 문제
丑戌未: 無恩之刑 — 은혜를 모름. 배신, 인간관계 단절
子卯: 無禮之刑 — 예의 없음. 성적 문제, 충동성
```

### 충과 합이 동시 발생할 때
```
합 + 충 동시: 합이 먼저이면 충의 힘 약화
충 + 합 동시: 충을 받은 후 합 → 합의 견고도 약화
삼합 형성 중 충: 삼합이 깨짐 (중간 글자 충거)
```
