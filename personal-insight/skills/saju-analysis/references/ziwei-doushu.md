# 자미두수(紫微斗數) 보조 분석 가이드

## 사주명리 × 자미두수 통합 원칙

```
명리사주: 오행의 流動(유동) — "언제" 어떤 기운이 흐르는가
자미두수: 별자리의 布局(포국) — "어디서" 어떤 사건이 발생하는가

두 체계는 상호 보완적:
명리 → 大운의 방향성과 시기적 흐름 분석
자미 → 구체적 궁(宮)별 사건 영역과 화기(化氣) 분석
```

**일치 원칙**: 두 체계가 같은 방향을 가리키면 고확률 예측.
**불일치 원칙**: 두 체계가 다른 방향을 가리키면 복수 시나리오 제시.

## 4화(四化) 분석 — 가장 중요

자미두수의 핵심은 **사화(四化)**: 화록(化祿)·화권(化權)·화과(化科)·화기(化忌)

| 화기 | 성격 | 의미 |
|------|------|------|
| **화록(化祿)** | 자성(磁性) 길 | 재물·인연이 끌려옴. 해당 궁이 번창 |
| **화권(化權)** | 강화 길 | 권력·통제력 강화. 해당 궁에서 주도권 |
| **화과(化科)** | 명예 길 | 학문·명성·문서 운. 시험 합격 |
| **화기(化忌)** | 흡수 흉 | 해당 궁의 에너지 차단, 걸림돌 |

### 유년 4화 적용법

```
유년의 간(干) → 해당 년도의 화록·화권·화과·화기 별 결정
이 별이 어느 궁에 있느냐 = 그 해 그 영역의 길흉

예: 유년 화기가 질액궁에 → 건강 주의, 사고 위험
    유년 화록이 재백궁에 → 재물 유입 기회
    유년 화기가 관록궁에 → 직업 변동·장애
    유년 화록이 부처궁에 → 결혼·이성 인연 강화
```

## 주요 주성(主星) 특성 요약

### 자미성(紫微星) — 황제성
```
특성: 권위, 고집, 리더십
명궁 자미: 리더 기질, 자존심 강함
재백궁 자미: 재물에 귀인 도움
```

### 천기성(天機星) — 지략성
```
특성: 두뇌, 전략, 변화
명궁 천기: 참모 기질, 지략가
천기 화록: 두뇌로 재물 획득
```

### 태양성(太陽星) — 남성·사업성
```
특성: 양기, 명예, 공적
명궁 태양: 공적 생활 중시, 남성적 기질
태양 화기: 아버지·남성 인연 장애
```

### 무곡성(武曲星) — 재물·금속성
```
특성: 재물, 의리, 과단성
명궁 무곡: 재물 능력, 군인·금융 적성
무곡 화록: 강한 재물 유입
```

### 천동성(天同星) — 복덕성
```
특성: 온화, 복덕, 의존성
명궁 천동: 낙천적, 복덕 있으나 추진력 약
```

### 염정성(廉貞星) — 囚星·관록성
```
특성: 정치, 법률, 도화, 囚禁
명궁 염정: 강한 사회적 욕망, 도화 성향
**염정 화기**: 관재구설, 소송, 감금 위험 — 질액궁 입명 시 특히 흉
```

### 천부성(天府星) — 재고성
```
특성: 보수적, 재물 축적, 안정
명궁 천부: 실무 능력, 재물 관리 우수
```

### 태음성(太陰星) — 여성·부동산성
```
특성: 음기, 부동산, 모성
명궁 태음: 섬세함, 부동산 인연
태음 화록: 부동산 이익
```

### 탐랑성(貪狼星) — 욕망·도화성
```
특성: 욕망, 이성 인연, 예술
명궁 탐랑: 다재다능, 이성 인연 풍부
탐랑 화기: 욕망으로 인한 재앙
```

### 거문성(巨門星) — 是非성
```
특성: 구설, 논쟁, 언변
명궁 거문: 말 잘함, 구설수
거문 화록: 언변으로 재물 획득 (강의·방송·협상)
```

### 천상성(天相星) — 인수성·문서
```
특성: 도움, 문서, 관인
명궁 천상: 조력자 인연, 문서 행정 적성
```

### 천량성(天梁星) — 의료·노인성
```
특성: 의료, 장수, 고독
명궁 천량: 의료 적성, 도덕성
```

### 칠살성(七殺星) — 장군성
```
특성: 결단, 독립, 孤剋
명궁 칠살: 강한 개척 정신, 부부 인연 불리
```

### 파군성(破軍星) — 변혁성

```
특성: 파괴, 창조, 혁신
```

## 자미두수 × 명리 교차 분석 포인트

### 재물운 교차 분석
```
명리: 세운에 재성 투출 + 용신 강화 = 재물 유입 가능
자미: 유년 화록이 재백궁 또는 관록궁 입명
→ 두 조건 일치 = 고확률 재물 유입 연도
```

### 건강운 교차 분석
```
명리: 용신 손상 + 조후 불균형 = 건강 취약
자미: 유년 화기가 질액궁 입명
→ 두 조건 일치 = 건강 위험 시기 경고
예: 유년 염정화기가 질액궁 → 스트레스성 질환, 수술 주의
```

### 직업·사업운 교차 분석
```
명리: 세운 관성 투출 + 대운 희신
자미: 유년 화권 또는 화록이 관록궁
→ 일치 = 승진·독립창업 최적 시기
```

### 결혼·이성운 교차 분석
```
명리 여명: 세운 관성 (정관 우선) 투출 + 일지 합
자미: 유년 화록이 부처궁 또는 명궁
→ 일치 = 결혼·중요한 이성 인연 시기
```
