## 1. 《자평진전(子平眞詮)》

**저자**: 심효첨(沈孝瞻) 청나라, 이후 서락오(徐樂吾) 평주(評注)로 완성됨

**핵심 이론: 격국론(格局論)**

### 격국 취용(取用)의 원칙
```
"八字用神，專求月令，以日干配月令地支，而生剋不同，格局分焉"
(팔자의 용신은 오로지 월령에서 구한다. 일간과 월령 지지를 배합하여
생극이 다름에 따라 격국이 나뉜다)
```

### 정격 8종 성패(成敗) 조건

| 격국 | 성격(成格) 조건 | 패격(敗格) 조건 |
|------|----------------|----------------|
| 정관격 | 재성·인성 보호 | 상관 혼입, 칠살 혼잡 |
| 편관격 | 식신제살 또는 인수화살 | 제살 없이 신약 |
| 정재격 | 비겁 없고 관인 보호 | 비겁과다 군겁쟁재 |
| 편재격 | 식상생재, 관성호위 | 비겁과다 분탈 |
| 정인격 | 관성생인 또는 재성 적절 | 식상으로 인성 극파 |
| 편인격 | 재성 제인(制印) 또는 식신설기 | 식신 없고 재성 없어 효신탈식 |
| 식신격 | 재성으로 식신생재 | 효신(편인) 혼입 탈식 |
| 상관격 | 재성으로 설기 또는 인성 제상관 | 정관 혼입 상관견관 흉 |

### 자평진전의 대운론
```
"행운喜神之鄉，無往不利；行運忌神之地，無往不凶"
(희신의 땅으로 가면 어디가도 이롭고, 기신의 땅으로 가면 어디가도 흉하다)

→ 대운의 천간지지가 모두 희신이면 대길운
→ 하나는 희신, 하나는 기신이면 길흉이 반반
→ 모두 기신이면 대흉운
```

## 2. 《적천수천미(滴天髓闡微)》

**원저**: 경도(京圖), 청나라 임철초(任鐵樵) 주해·확장

**핵심 이론: 일간론·억부론·형상론**

### 천간 10간의 핵심 구절

```
甲木: "甲木參天，脫胎要火，春不容金，秋不容土，火熾乘龍，水蕩騎虎，地潤天和，植立千古"
→ 갑목은 하늘로 솟고, 태어나는데 화가 필요하며, 봄에는 금을 받지 않고, 가을에는 토를 받지 않는다

乙木: "乙木雖柔，刲羊解牛，懷丁抱丙，跨鳳乘猴，虛濕之地，騎馬亦憂，藤蘿繫甲，可春可秋"
→ 을목은 부드러우나 양과 소를 잡을 수 있다

丙火: "丙火猛烈，欺霜侮雪，能煅庚金，逢辛反怯，土衆成慈，水猖顯節，虎馬犬鄉，甲來成滅"
→ 병화는 맹렬하여 서리를 업신여기며, 경금을 단련할 수 있다

丁火: "丁火柔中，內性昭融，抱乙而孝，合壬而忠，旺而不烈，衰而不窮，如有嫡母，可秋可冬"
→ 정화는 중간에서 유연하고, 을목을 안고 효성스럽다

戊土: "戊土固重，旣中且正，靜翕動闢，萬物司命，水潤物生，火燥物病，若在艮坤，怕沖宜靜"
→ 무토는 굳고 무거우며, 중정하다

己土: "己土卑濕，中正蓄藏，不愁木盛，不畏水狂，火少火晦，金多金光，若要物旺，宜助宜幫"
→ 기토는 낮고 습하며, 중정하게 저장한다

庚金: "庚金帶殺，剛健為最，得水而清，得火而銳，土潤則生，土乾則脆，能贏甲兄，輸於乙妹"
→ 경금은 살기를 띠고 강건함이 으뜸이며, 물을 얻으면 맑아지고 불을 얻으면 날카로워진다

辛金: "辛金軟弱，溫潤而清，畏土之多，樂水之盈，能扶社稷，能救生靈，熱則喜母，寒則喜丁"
→ 신금은 부드럽고 약하며, 온화하고 맑다

壬水: "壬水通河，能洩金氣，剛中之德，周流不滯，通根透癸，沖天奔地，化則有情，從則相濟"
→ 임수는 강으로 흐르고, 금의 기운을 설기할 수 있다

癸水: "癸水至弱，達於天津，得龍而運，功化斯神，不愁火土，不論庚辛，合戊見火，化象斯真"
→ 계수는 지극히 약하나, 천진(天津)에 이른다
```

### 억부론(抑扶論)의 핵심
```
"旺者宜洩宜剋，衰者宜生宜助，要在中和為美"
(왕성한 것은 설기하거나 극함이 마땅하고, 쇠약한 것은 생하거나 돕는 것이 마땅하다.
중화가 아름답다)
```

## 3. 《궁통보감(窮通寶鑑)》

**별명**: 난강망(欄江網)

**핵심 이론: 조후론(調候論)**

### 기본 원리
```
月令은 계절. 사주가 너무 차거나(寒), 뜨겁거나(熱), 건조하거나(燥), 습한(濕) 것을 
균형잡는 글자가 조후용신.
"寒者暖之，熱者涼之，燥者潤之，濕者燥之"
(차가운 것은 따뜻하게, 뜨거운 것은 시원하게, 건조한 것은 습하게, 습한 것은 건조하게)
```

### 월지별 경금(庚金) 조후 처방 (예시)

| 월지 | 절기 | 경금의 상황 | 조후 처방 |
|------|------|------------|-----------|
| 寅月(1월) | 초봄 | 금기 약, 목왕 | 丁火 단련 + 甲木 보조 |
| 卯月(2월) | 중춘 | 목기 극성 | 庚金 자신 강화 + 丁火 |
| 辰月(3월) | 늦봄 | 습토 과잉 | 甲木 소토 + 壬水 세척 |
| 巳月(4월) | 초여름 | 화기 과잉 | 壬水 우선 |
| 午月(5월) | 중하 | 화기 극성 | 壬水 필수 + 癸水 보조 |
| 未月(6월) | 늦여름 | 조토 과잉 | 壬水 윤금 |
| 申月(7월) | 초가을 | 금기 왕성 | 丁火 단련 + 甲木 소토 |
| 酉月(8월) | 중추 | 금기 최왕 | 丁火 필수 |
| **戌月(9월)** | **늦가을** | **토다금매 위험** | **先甲疏土，後壬洗金** |
| 亥月(10월) | 초겨울 | 수기 과잉 | 丁火 우선 |
| 子月(11월) | 중동 | 한냉 | 丙火·丁火 조후 |
| 丑月(12월) | 늦겨울 | 한습 최강 | 丙火 必需 |

> **경신일 무술월 핵심 처방**: "九月庚金，戊土司令，最怕土厚埋金。宜先用甲疏，後用壬洗，則金自出矣。壬甲兩透，科甲相宜"

## 4. 《삼명통회(三命通會)》

**저자**: 만민영(萬民英), 명나라

**핵심 이론: 신살론·일주론**

### 경신(庚申) 일주론
```
"庚申，坐祿通根，身體好，主富貴"
(경신은 건록에 앉아 뿌리가 통하여 신체가 좋고, 부귀를 주관한다)

"手足不停，為人清高，利官近貴，夫妻口角，煩多愛少"
(손발이 쉬지 않고, 사람됨이 청고하며, 관직에 유리하고 귀인을 가까이 한다.
부부간 말다툼이 있고 번민이 많으며 사랑이 적다)
```

### 식신(食神)과 효신탈식(梟神奪食)
```
"惟剋食最凶，故有梟神之號"
(오직 식신을 극하는 것이 가장 흉하므로 효신이라는 호칭이 있다)

"食神大忌偏印為倒食，主為人有始無終"
(식신은 편인의 도식을 가장 꺼리니, 사람됨이 시작은 있으나 끝이 없다)

"食神制殺，逢梟不貧則夭"
(식신제살 구조에서 효신을 만나면 가난하지 않으면 요절한다)
```

### 금백수청(金白水清)
```
"金白水清之類，當登科第"
(금백수청의 무리는 마땅히 과거에 급제한다)
→ 경금이 임수·계수를 만나 맑아지는 최상의 조합
```

## 5. 《연해자평(淵海子平)》

**핵심**: 중국 명리학의 원전적 교과서. 십성론, 신살론, 육친론의 기초를 수립

### 격국과 운의 관계
```
"格局喜用神逢生旺，忌神逢死絶"
(격국은 희용신이 생왕을 만나는 것을 기뻐하고, 기신이 사절을 만나는 것을 꺼린다)
```

### 여명론(女命論) 기본 원칙
```
"女命以官為夫，以財為婆，以食傷為子女"
(여명은 관성을 남편으로, 재성을 시어머니로, 식상을 자녀로 삼는다)

"女命官星有力，夫健而賢；官星無力，夫弱或缺"
(여명에서 관성이 유력하면 남편이 건강하고 현명하며, 무력하면 남편이 약하거나 없다)
```

## 6. 《명리정종(命理正宗)》

**저자**: 장남(張楠), 명나라

**핵심**: 중급 실전 명리. 격국론과 일주론을 결합한 응용 분석

### 비겁태왕(比劫太旺) 처리법
```
"比劫太旺，財星必受傷，若無官殺制之，則財破妻傷，一事無成"
(비겁이 매우 왕성하면 재성이 반드시 상처를 입고, 만약 관살이 제어하지 않으면
재물이 파하고 처를 상하며 아무것도 이루지 못한다)

→ 비겁태왕의 해법: 식상설기(우선) → 관살제비(차선) → 재성으로 직접 취재(불가)
```

## 7. 용신론 학파별 비교

| 학파 | 주요 문헌 | 용신 결정 방법 | 특징 |
|------|-----------|----------------|------|
| 格局用神派 | 자평진전 | 月令格局 기준 | 체계적, 사회적 성취 분석 우수 |
| 抑扶用神派 | 적천수 | 신강/신약 기준 억부 | 운 흐름 분석 우수 |
| 調候用神派 | 궁통보감 | 계절 한열 균형 | 개인 건강·기질 분석 우수 |
| 病藥用神派 | 명리정종 | 사주의 病을 찾아 藥을 용신으로 | 문제 해결 중심 |
| 通關用神派 | 삼명통회 | 두 세력 사이 소통 | 갈등 구조 분석 우수 |

**현대 실전 적용 순서**: 억부 → 격국 → 조후 → 통관/병약 (보완)
