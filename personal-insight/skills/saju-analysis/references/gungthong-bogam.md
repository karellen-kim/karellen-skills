# 궁통보감(窮通寶鑑) 월지별 조후 처방 요약

## 원칙
"사주는 사람이고, 월지는 사람이 태어난 계절의 기후다.
그 기후가 너무 차거나 뜨겁거나 건조하거나 습하면 균형을 잡아주는 글자가 필요하다."

아래는 10천간 × 12월령의 조후 처방 중 **실전에서 가장 많이 활용되는 조합**을 중심으로 요약.

## 庚金 일간 조후 처방 (전체)

### 핵심 원리
경금은 "원광(原鑛)" — 제련되지 않은 원석. 반드시 丁火로 단련하고 甲木으로 재목을 만들어야 가치가 있다.
여름에는 壬水로 씻어야 하고, 겨울에는 丁火 없이는 쓸모없다.

## 조후 분석 실전 적용법

```
1단계: 월지 확인 → 어느 계절인가?
2단계: 원국 오행 편중 파악 → 어느 오행이 과다·과소한가?
3단계: 조후 처방 글자 확인 → 원국에 있는가? 없는가?
4단계: 대운·세운에서 조후 글자 유입 시기 = 길운 시점

조후 결핍 시 나타나는 현상:
- 火 결핍(한냉 사주): 의욕 저하, 우울증, 혈액순환 이상
- 水 결핍(염열 사주): 충동성, 고혈압, 화기병(火氣病)
- 木 결핍(금기 과다): 창의성 부족, 재물 창출 어려움
- 土 결핍(수기 과다): 판단력 흐림, 기반 불안정
```
