# 신살(神殺)·길성(吉星) 완전 가이드

## 원칙
- 신살은 **사건의 양상(how)**을 구체화하지, **길흉(whether)**을 결정하지 않는다
- 격국·용신이 작동하는 방향을 신살이 구체화하는 것
- 용신 오행의 신살 = 길성으로 작동 / 기신 오행의 신살 = 흉성으로 작동

---

| 申子辰 | 巳 | 午 | 未 | 申 | 酉 | 戌 | 亥 | 子 | 丑 | 寅 | 卯 | 辰 |

| 寅午戌 | 亥 | 子 | 丑 | 寅 | 卯 | 辰 | 巳 | 午 | 未 | 申 | 酉 | 戌 |

### 핵심 12신살 의미

| 신살 | 의미 | 구체 현상 |
|------|------|-----------|
| **역마살(驛馬)** | 이동·변화 | 이직, 이사, 해외, 출장, 사업 확장 |
| **화개살(華蓋)** | 고독·예술·종교 | 예술적 기질, 출가 인연, 고독한 천재 |
| **도화살(桃花)** = 년살 | 인기·이성 | 매력, 연애 인연, 예능인 기질 |
| **망신살(亡身)** | 망신·폭로 | 비밀 드러남, 체면 손상, 관재 |
| **겁살(劫殺)** | 강탈·강압 | 강도·사기 피해, 외부 폭력적 상황 |
| **재살(災殺)** = 수옥살 | 감금·구속 | 소송, 구속, 병원 입원 |
| **반안살(攀鞍)** | 안정·문서 | 부동산 계약, 승차, 이동 안정 |
| **장성살(將星)** | 리더십 | 지도자, 군인, 조직장 |
| **월살(月殺)** | 고집·소통 단절 | 이해받지 못함, 외로운 결정 |

## 주요 신살 상세

### 역마살(驛馬殺)
```
산출: 년지 또는 일지가 申子辰 → 寅, 亥卯未 → 巳, 寅午戌 → 申, 巳酉丑 → 亥
의미: "馬不停蹄(말이 발굽을 멈추지 않는다)" — 끊임없는 이동과 변화
길작용: 용신 대운·세운에서 → 해외 사업 성공, 원거리 발전
흉작용: 기신 대운·세운에서 → 이사 강제, 직업 불안정, 타향에서의 고생
역마충: 두 역마가 충을 이루면 "역마가 가장 강하게 발동" — 대이동
```

### 도화살(桃花殺)
```
산출: 년지 또는 일지 기준 子午卯酉 위치
의미: 異性緣과 사회적 매력
길작용: 예능인, 서비스업, 영업, 교육 — 인기 직종에서 빛남
흉작용: 음란·외도·주색 문제, 결혼 이후 이성 문제
위치별:
  년지 도화: 선천적 매력, 어린 시절부터 인기
  월지 도화: 직업적 매력, 사회생활에서 도화 발현
  일지 도화: 배우자도 도화 성향, 부부 관계에 영향
  시지 도화: 말년까지 이성 인연, 자녀도 매력적
```

### 화개살(華蓋殺)
```
산출: 년지·일지 기준 辰戌丑未 자리
의미: 관(冠)을 화려하게 덮는다 — 고독한 빛
특성: 예술적 재능, 종교·철학적 성향, 외로운 천재성
화개 중첩(2개 이상): 출가·종교 귀의 인연, 또는 고독한 예술의 길
```

### 양인살(羊刃殺)
```
산출: 
  甲日 → 卯, 乙日 → 辰, 丙日·戊日 → 午
  丁日·己日 → 未, 庚日 → 酉, 辛日 → 戌
  壬日 → 子, 癸日 → 丑
의미: 칼날 — 강한 추진력과 잔인성의 양면
길작용: 군인·경찰·외과의사·운동선수 등 숙살지기 필요 직업
흉작용: 관재·사고·수술·대인 충돌
양인격: 일지에 양인 + 월지에 편관(칠살) = 양인가살 — 군인·무인의 명
```

### 괴강살(魁罡殺)
```
해당 일주: 庚辰·庚戌·壬辰·壬戌 (4개 일주)
의미: 하늘의 강신(剛神)이 집결한 자리
특성: 극단적 성격. 승리하면 대성, 실패하면 처참
수재·군인·정치가 多 — 평범하지 않은 운명
괴강이 충을 받으면: 대파 발생 (수술·이혼·사고 등 극단적 사건)
```

## 길성(吉星) 가이드

### 천을귀인(天乙貴人)
```
일간별 산출:
甲戊庚 → 丑未, 乙己 → 子申, 丙丁 → 亥酉
壬癸 → 卯巳, 辛 → 午寅

의미: 귀인이 나를 돕는 별. 어려운 순간에 구원자 출현
위치별: 년지·월지·일지·시지에 있으면 각각 조상·직장·배우자·자녀 귀인
```

### 천의성(天醫星)
```
산출: 생월 기준 전월 지지
예: 월지 戌月 생 → 酉가 천의성

의미: 의료·치유 능력. 의사·한의사·간호사·심리치료사 적성
천의성 + 화개살: 종교적 치유자, 무속 인연
```

### 문창귀인(文昌貴人)
```
일간별 산출:
甲 → 巳, 乙 → 午, 丙·戊 → 申, 丁·己 → 酉
庚 → 亥, 辛 → 子, 壬 → 寅, 癸 → 卯

의미: 학문·문장·지식 능력. 시험 합격, 저술 능력
```

### 금여성(金輿星)
```
일간별 산출:
甲 → 辰, 乙 → 巳, 丙 → 未, 丁 → 申
戊 → 未, 己 → 申, 庚 → 戌, 辛 → 亥
壬 → 丑, 癸 → 寅

의미: 황금 수레 — 귀한 배우자 또는 귀인 탑승. 좋은 배우자 인연
```

### 정록(正祿)
```
산출: 일간의 건록지
甲 → 寅, 乙 → 卯, 丙·戊 → 巳
丁·己 → 午, 庚 → 申, 辛 → 酉, 壬 → 亥, 癸 → 子

의미: 나의 녹(祿)이 있는 자리. 재록이 풍부, 안정적 수입
```

### 홍염살(紅艷殺)
```
일간별 산출:
甲 → 午, 乙 → 午, 丙 → 寅, 丁 → 未
戊 → 辰, 己 → 辰, 庚 → 戌, 辛 → 酉
壬 → 子, 癸 → 申

의미: 붉은 매력. 도화살과 유사하나 더 강렬한 이성 매력, 예술적 감수성
```

### 현침살(懸針殺)
```
해당 천간: 甲·申·辛·卯 등이 포함된 구조
의미: 바늘이 드리워진 살 — 의료(침, 수술) 적성 또는 예리한 도구 관련
천의성과 겹치면: 의료 분야 강한 적성
```

## 신살 중첩 패턴

| 중첩 조합 | 의미 |
|-----------|------|
| 도화살 + 홍염살 | 강한 이성 매력, 연애 인연 풍부 |
| 역마살 + 화개살 | 종교적 여행자, 순례자 기질 |
| 역마살 + 망신살 | 이동 중 망신 사건 주의 |
| 양인살 + 겁살 | 외과적 사건(수술·사고) 주의 |
| 천의성 + 문창귀인 | 의학 연구·학문적 치유 분야 |
| 괴강살 + 양인살 | 강렬한 숙살지기, 군인·무인의 명 |
